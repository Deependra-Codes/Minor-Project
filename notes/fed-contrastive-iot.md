# Federated Contrastive Learning for IoT Anomaly Detection — Preprints.org 2026 (NOT peer-reviewed)
- Problem: IoT anomaly detection with private data spread over devices with different data distributions.
- Dataset: N-BaIoT (real IoT devices: cameras, baby monitors, doorbells, thermostats).
- Method: local encoders per device + contrastive representation alignment + federated aggregation.
- Results: Acc 0.948, AUC 0.972, F1 0.944 (vs GAT 0.917 acc).
- Gaps: not peer-reviewed; future work = larger federated setups, lightweight edge models, communication compression.
